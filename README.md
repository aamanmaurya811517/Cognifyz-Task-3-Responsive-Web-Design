# Cognifyz Task 3 – Responsive Web Design

A modern, responsive, and interactive educational website developed as part of the **Cognifyz Technologies Web Development Internship Program**.

The project, named **Cognifyz Learning Hub**, provides a user-friendly platform where visitors can explore courses, learn about educational opportunities, submit enrollment details, and contact the platform.

---

## 📌 Project Overview

Cognifyz Learning Hub is a multi-page educational website designed with a clean interface, responsive layouts, modern styling, and interactive elements.

The primary objective of this project is to demonstrate practical knowledge of frontend development, responsive web design, Bootstrap, JavaScript, Node.js, Express.js, and EJS templating.

The website focuses on usability, visual presentation, navigation, and responsiveness across different screen sizes.

## 🎯 Objectives

- Develop a modern and responsive educational website.
- Create a clean and professional user interface.
- Implement multi-page navigation.
- Display educational courses in an organized layout.
- Create an enrollment form with validation.
- Use reusable EJS components.
- Apply CSS animations and transitions.
- Ensure compatibility with desktop, tablet, and mobile devices.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### Prerequisites

Make sure the following software is installed:

- Node.js
- npm (Node Package Manager)
- Visual Studio Code (recommended)
- Git

### Step 1: Clone the Repository

```bash
git clone https://github.com/aamanmaurya811517/Cognifyz-Task-3-Responsive-Web-Design.git
```

### Step 2: Navigate to the Project Directory

```bash
cd Cognifyz-Task-3-Responsive-Web-Design
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Application

```bash
node server.js
```

### Step 5: Open in Browser

Visit:

```text
http://localhost:3000
```

The Cognifyz Learning Hub website should now be running locally.

The website includes form validation to improve the accuracy of user-submitted information.

Validation and form handling are implemented through client-side JavaScript and server-side Express functionality where applicable.

**Note:** Form submissions use temporary in-memory handling. A persistent database has not been configured for this project.
